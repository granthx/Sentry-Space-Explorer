Spacecraft Anomaly Detection

An LSTM autoencoder learns the normal rhythm of spacecraft sensor readings and flags anything unusual — a drifting sensor, a sudden spike, a systematic shift. Data comes from NASA's SMAP satellite and the Curiosity rover, with anomalies labelled by engineers at NASA JPL.

How the LSTM autoencoder works

  1. Windowing — The sensor time series is split into overlapping 25-step windows with a stride of 5.
  2. Normalisation — Each window is zero-mean unit-variance normalised so the model is amplitude-agnostic.
  3. Autoencoder reconstruction — The LSTM encoder compresses each window to a latent vector; the decoder reconstructs the original. Normal windows reconstruct well; anomalous ones do not.
  4. Threshold — Windows whose reconstruction error exceeds the 95th percentile of training errors are flagged as anomalies.
  5. Severity — Anomaly rate drives severity: <5% low, 5–20% medium, >20% high.
